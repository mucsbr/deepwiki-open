# 免登录 Ask

访客入口为 `/ask/public`；原 `/ask` 继续使用 GitLab 登录和用户权限。

在后台 `/admin` 的「免登录 Ask」页签添加 bas、easm 等逻辑分组，逐个勾选
已索引或部分索引可用的仓库，再开启并保存公开设置。分组不会自动纳入整个
GitLab 组、新建仓库或现有 Products。默认不开启，配置保存到
`~/.adalflow/metadata/public_ask.json`，支持通过 `PUBLIC_ASK_SETTINGS_PATH` 改路径。
配置带版本号及原子写入，两个管理员同时编辑时会提示重新加载。

访客只能选择开放的分组。服务端按已选分组解析仓库，每次提问、读取会话、
恢复任务、重连事件流和调用源码/Wiki 工具都会检查开放范围。关闭分组或移除
仓库后，旧会话也不能继续读取该范围，须新建会话，避免旧上下文泄露已撤权的
源码。后台新增仓库后，在原会话发送下一条消息时自动解析最新分组成员，检查
本地已完成索引，并使用新增仓库；不需要丢弃历史证据。历史轮次保留各自的实际
源码范围；「原样继续分析」和压缩不会扩展旧任务范围。页面显示下一次新消息
将使用的仓库数。选择其他分组应新建会话。每轮最多 100 个仓库，与登录版一致；
分组合计超限或新增仓库索引不可用时会明确报错，不静默少选仓库。

每个浏览器自动生成随机访客密钥，无需账号；API 仅保存密钥的 SHA-256 摘要。
会话、消息、SSE 和生成文档均验证所属访客，登录版历史与访客历史按身份命名空间隔离。
同一浏览器配置的标签页共享访客身份；不同浏览器、无痕窗口或设备相互隔离。
清理浏览器数据后无法重新访问该身份的旧历史。密钥不进入 URL、日志或模型上下文。

自定义系统提示词按会话保存，每次提问另存不可变快照。留空使用原默认提示词，
恢复任务沿用任务原提示词。自定义指令不改变服务器的仓库白名单或工具权限。
访客使用运营方配置的默认 Agent 模型，不能提交任意 provider/model 覆盖它。

停止或超时后，可以在原会话补充要求并发送：保留已有源码证据，不重新执行
旧的待调用工具；新要求直接使用本地已完成版本并安排独立后台更新。「原样继续分析」则恢复最新分析任务，
不添加新指令。发送新问题后不能再恢复更早的任务，以免同一上下文执行旧目标。

Ask 不等待代码更新：本轮继续读取已完成的代码和索引，后台发现 GitLab 有更新时
才拉取并重建；完成后下一次新提问使用新版本。同仓库跨访客合并更新任务，滚动
24 小时最多安排一次检查（失败和没有变化也计入）；管理页手动 Index 不受此限制。
同仓库后台更新与管理端 Index 共用写锁。停止分析不取消独立更新；重启自动恢复
更新队列，分析任务则保留历史与 checkpoint，待用户点击继续，不自动执行旧问题。

页面显示上下文 token 用量与配置预算，区分「最近请求的服务商实际用量」和
「估算」；这不是账号余额，也不等于模型官方最大窗口。自动整理上下文会显示
进度。停止分析后可点「压缩上下文」，使用 DeepAgents 原生手动压缩引擎，
保留原始历史且不会自动继续分析；上下文较小时会提示无需压缩。压缩任务和
分析共用队列，支持停止，权限及访客隔离规则相同。`AGENT_SUMMARY_TOKENS`
默认 2000，仅限制摘要输出；不会限制调查轮数或最终答案长度。
当前网关模型的上下文默认预算为 `AGENT_CONTEXT_TOKENS=1000000`，在 85%
（约 850000 tokens）触发自动压缩。摘要生成总额度为
`AGENT_SUMMARY_GENERATION_TOKENS=8192`，包括可能的推理 token，与最终摘要
长度分开。空摘要最多重试一次；仍为空则保留上下文并明确提示可恢复，不把
失败检查点当作已完成。日志仅记录结束原因和用量，不记录摘要正文或推理内容。

登录版和访客版共用异步任务池：`AGENT_MAX_CONCURRENT_RUNS=4` 控制同时分析数，
`AGENT_MAX_QUEUED_RUNS=32` 控制等待任务数。等待不计入分析超时，排队任务可停止；
每个访客身份最多一个排队/运行任务，避免同一浏览器占满任务池。API 仍应只运行
一个 worker；单 worker 不等于单用户。
